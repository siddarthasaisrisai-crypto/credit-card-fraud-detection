# Credit Card Fraud Detection Using Machine Learning

A reconstructed learning/demo version of the project described in the resume. It trains a Random Forest classifier on a CSV dataset and scores transactions entered through a console menu. Transaction records and predictions are saved to CSV files.

## Requirements
- Python 3.10+
- Install dependencies: `pip install -r requirements.txt`

## Run
1. Open this folder in VS Code.
2. Run `pip install -r requirements.txt`
3. Run `python main.py`

The included `data/transactions.csv` is synthetic sample data for demonstration only. Do not use it to make real financial decisions. For real-world use, obtain a properly licensed, representative dataset, validate the model, and implement privacy/security controls.
